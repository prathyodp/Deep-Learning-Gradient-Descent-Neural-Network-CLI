# Deep Learning Gradient Descent & Neural Network CLI

A reproducible command-line project for **linear regression with gradient descent** and a small **feed-forward neural network**. It demonstrates:
- NumPy manual forward/backward propagation (explicit gradients)
- TensorFlow and PyTorch training backends (autograd)
- Custom activation functions: ReLU, sigmoid, tanh, linear
- Data annotation, configurable experiments, metrics, and DVC pipeline tracking

> The project runs on a generated regression dataset by default. Replace it with your own CSV using `--data`.

## 1. Environment

Recommended: Python 3.10 or 3.11.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt
```

TensorFlow and PyTorch are optional backends; install the one(s) you plan to use:
```bash
pip install tensorflow
pip install torch
```
For GPU builds, follow the official installation instructions for your OS and hardware.

## 2. Quick start

Generate a dataset and train with the manual NumPy implementation:
```bash
python -m src.cli train --backend numpy --model linear --epochs 300 --learning-rate 0.03
```

Train a neural network:
```bash
python -m src.cli train --backend numpy --model mlp --hidden 16 --activation tanh --epochs 500
```

Use TensorFlow or PyTorch:
```bash
python -m src.cli train --backend tensorflow --model mlp --activation relu
python -m src.cli train --backend pytorch --model linear
```

Evaluate a saved model:
```bash
python -m src.cli evaluate --model-path artifacts/model.json
```

Annotate a CSV with target bands:
```bash
python scripts/annotate_data.py --input data/raw/regression.csv --target y --output data/processed/annotated.csv
```

## 3. CLI commands

`train` options:
- `--backend`: `numpy`, `tensorflow`, `pytorch`
- `--model`: `linear` or `mlp`
- `--activation`: `relu`, `sigmoid`, `tanh`, `linear`
- `--epochs`, `--learning-rate`, `--hidden`, `--seed`
- `--data`: optional CSV path; first columns are features and `--target` is the label column
- `--target`: target column name (default `y`)

`evaluate` reads the model metadata and reports metrics on the generated/selected data. The training command stores weights, predictions, metrics and a JSON run record in `artifacts/`.

## 4. Project layout

```text
data/
  raw/                 generated or user-provided source CSV
  processed/           annotated dataset
src/
  cli.py               command-line entry point
  data.py              data loading and deterministic dataset generation
  models.py            NumPy manual backprop, TensorFlow and PyTorch models
  train.py             training orchestration and metrics

  annotate_data.py     reproducible data annotation utility
configs/
  params.yaml          DVC hyperparameters
  tuning.yaml          candidate hyperparameter grid
artifacts/             model and metrics outputs
reports/               experiment and execution logs
dvc.yaml               reproducible pipeline
params.yaml             root DVC parameter file
```

## 5. DVC experiment workflow

Install DVC:
```bash
pip install "dvc"
git init
dvc init
```

Run the pipeline:
```bash
dvc repro
```

Change values in `params.yaml`, then:
```bash
dvc repro
dvc metrics show
dvc params diff
```

For remote storage, configure your own remote (example syntax):
```bash
dvc remote add -d storage <your-storage-url>
dvc push
```

DVC tracks pipeline definitions, parameters, dependencies, and outputs. Git tracks the code/configuration; DVC tracks data/model artifacts according to the configured stages and `.gitignore`.

## 6. Hyperparameter tuning

`configs/tuning.yaml` lists candidate values. A small grid runner is provided:
```bash
python scripts/tune.py --backend numpy --model mlp
```
It writes a CSV leaderboard to `reports/tuning_results.csv`. The default grid is intentionally small for laptop/CPU execution.

## 7. Reproducibility and logs

- Fixed random seeds are used for generated data and model initialization.
- `artifacts/run.json` records backend, model, hyperparameters, and metrics.
- `reports/technical_execution_log.md` is a template. Append actual commands, environment details, and outcomes after running locally.
- `reports/experiment_log.csv` is generated by training/tuning runs.

## 8. Important implementation note

The NumPy backend computes gradients explicitly using the chain rule, making the backpropagation steps inspectable. TensorFlow and PyTorch backends use their automatic differentiation engines to calculate gradients. The custom activation functions are defined in the project and used by all backends. Linear regression uses a linear output layer; the MLP supports a selected hidden activation and linear output.
